## 文档约定

- 中文正文，键名、命令、日志文案、源码路径保留原文，方便直接搜索。
- 关键结论标注源码出处（`文件:行号` 或包路径）；没有实机验证支撑的部分显式写成「推断」并给出依据，不把猜测当事实。
- 枚举用表格，流程用 `text` 代码块，命令用 `bash`，避免图表渲染依赖。
- 所有 Markdown 必须经 `markdownfmt` 格式化：提交前跑 `make format-markdown`（或对单文件跑 `markdownfmt -w`）。
- 不写「待补充」「TODO」占位；没写完的章节宁可不留。

## 名词表

| 名词            | 含义                                                                         |
|-----------------|------------------------------------------------------------------------------|
| trim-music      | 飞牛音乐的后端服务，本代理要接管的就是它的 unix socket                       |
| 上游 / upstream | 官方 trim-music 被改名后的 socket：`/var/run/trim_music_upstream.socket`     |
| 接管 / 旁路     | 把官方 socket 改名占位，代理在原路径监听；旁路指代理只读流量、不修改转发内容 |
| scrobble        | 向 Last.fm / ListenBrainz 上报一条「听完了」记录；now playing 则是「正在听」 |
| MBID            | MusicBrainz 实体 ID（录音/艺人/专辑），用于精确匹配曲目                      |
| GUID            | 飞牛音乐曲目的内部唯一 ID，歌单写入时用的就是它                              |
| fpk             | 飞牛应用包格式；`fpk` 构建下部分子命令不编译，路径由 `TRIM_*` 环境变量决定   |
| gatewayPrefix   | Web UI 在飞牛统一网关下的固定前缀 `/app/fnmusic-sync`                        |
